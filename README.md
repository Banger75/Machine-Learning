- **Model development:** Data exploration, preprocessing, training, and model evaluation, depending on the notebook.

## How to explore

1. Select a notebook from the index above and open it in GitHub or Jupyter.
2. Check its imports and dataset paths; individual notebooks may need additional datasets or packages not stored in this repository.
3. Use a virtual environment and install only the dependencies needed for the selected notebook.
4. Re-run the notebook on appropriately sourced data before relying on any saved output.

## Recommended review criteria

For a professional Data Science case study, each notebook should clearly document:

- The problem being solved and why it matters.
- Dataset source, size, target variable, and limitations.
- Train/test split and precautions against data leakage.
- Baseline comparisons and evaluation metrics suitable for the task.
- Interpretable results, limitations, and next steps.
